# forms

Texas forms questionnaire system — boolean-first questionnaire that interviews a user and produces filled-out motions and pleadings ready to file.

## Where to start

- **`SPECS.md`** — product manifesto and methodology ("Twenty Questions" interview model, Prospecting Tool v1, codes library, case-law refresh).
- **`HANDOFF.md`** — current engineering state and phase plan.
- **`CLAUDE.md`** — durable project rules, auto-loaded by Claude Code sessions in this repo.
- **`catalog/fields.yaml`** — canonical field schema; every form manifest references keys defined here.
